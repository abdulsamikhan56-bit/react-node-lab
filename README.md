\# React + Raw Node.js Integration



\## Objective

To connect a React frontend with a Raw Node.js backend using HTTP requests and a REST API.



\## Technologies Used

\- React

\- Node.js

\- JavaScript

\- HTTP Module

\- REST API



\## Backend

The backend runs on port 5000.



API Endpoint: http://localhost:5000/api/info



\## Frontend

The React frontend runs on port 3000 and uses useEffect(), useState(), and fetch() to get and display data from the backend.



\## API Response

React is communicating with Node.js



\## How to Run

1\. Run `node backend/server.js` from the root folder.

2\. Open another terminal.

3\. Navigate to the frontend folder using `cd frontend`.

4\. Run `npm start`.

5\. Open http://localhost:3000 in your browser.
